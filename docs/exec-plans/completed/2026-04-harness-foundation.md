# 2026-04 Harness Foundation

状态：已完成

## 背景

这个仓库后续还会持续迭代。当前最明显的问题不是功能做不出来，而是：

- 启动入口和构建脚本开始漂移
- 单一 `PRD.md` 过长，且容易和代码现实失配
- 配置约束分散在代码里，缺少统一校验
- 仓库缺少一个快速告诉后来者“从哪看、怎么跑、怎么验”的骨架

## 这次迭代的目标

- 补上真实可运行的 `cmd/monitor` 启动入口
- 把交易所支持范围和配置约束收敛成代码里的单一事实来源
- 引入低成本的 `doctor` 自检
- 用 `AGENTS.md + docs/` 取代单体 `PRD.md`

## 已完成

- 新增 `cmd/monitor/main.go`
- 新增交易所名称规范化与配置校验
- `POST /api/config` 改为校验失败时直接返回错误
- 新增 `scripts/doctor.sh` 与 `make doctor`
- 删除顶层 `PRD.md`
- 新增分层文档骨架

## 完成情况

- `doctor` 已接入镜像发布 CI
- `cmd/monitor` 已增加启动集成验证
- 历史 API 与前端通过 `/api/meta` 共享交易所响应契约
- 运行时配置继续保持仅更新内存态，持久化配置仍为明确非目标

## 决策记录

- 不一次性引入复杂 linter 或重型流程
